Jamfbreak-v1.0.8 (2026-10-30)
=============================

- Changed: every card border in the app is removed — the console, device
  info tiles, status pill and settings dialog now rely on layered panel
  tones only, no outlines anywhere.
- Changed: the console now matches the redesign mockup exactly — the
  Console title and copy/refresh buttons wrap around a darker, inset,
  borderless scrollable output area.
- Changed: the device info grid now sits inside a soft grey rounded
  container that wraps the two-column tiles, like the mockup.
- Core bypass pipeline, donor routing and safety controls are unchanged
  from v1.0.7.

Jamfbreak-v1.0.6 (2026-10-29)
=============================

- Fixed: the redesigned GUI showed only a black window in the packaged exe.
  Root cause: pywebview loaded the bundle through NavigateToString (an
  opaque about:blank origin) where this Vite module bundle refuses to
  execute. The GUI now decodes the same compiled frontend to a temp HTML
  file and loads it as a file:// URL; the app, bridge and settings all
  mount and respond exactly as in the browser preview.
- App version stamp bumped to 1.0.6; bypass pipeline, donor routing and
  all safety controls are unchanged.

Jamfbreak-v1.0.4 (2026-10-27)
==============================

- New: iOS 26.6.2 - 27.0.1 (iPhone and iPad) bypass support via the modern donor path.
  - iPhones use backups/ios26-iphone/, iPads use backups/ios26-ipad/.
  - Devices above iOS 27.0.1 are refused before any device modification.
- The third-party batch wrapper is never executed; the flow is implemented natively
  with idevicebackup2 restore --system --settings --skip-apps --no-reboot.
- Reboot only happens after a successful (exit 0) restore, as before.
- UI is unchanged from v1.0.3.
